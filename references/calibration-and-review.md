# 校准与复核契约

跨设备稳定的是明确标准、证据结构和工具行为，不是让不同模型输出相同题面。请先完整读取内置基准，按题位进行生成；每完成一个模块先复核，再整卷复核。不要仅向模型喊“提高质量”。

## 学科校准例（原创，非固定试卷题）

- 条件：仅通过标定的仪器可进入试验室；有些通过标定的仪器需要冷藏。可保证“有些需要冷藏的仪器通过标定”，不能保证“所有通过标定的都可进入”。正确关系为进入→标定，而非逆命题。检验的是方向和量词，换题时不能复用这组仪器条件。
- 语义：材料只说“在低风速环境测试有效”，错项改为“适用于所有天气”。这是真实范围扩大机制；另三个错项如果都用“任何、永远、完全”，会产生明显排错提示，须改为有相近语义的局部误读。
- 数据：现期总量271.6、同比12.8%，基期约240.78；271.6×(1−12.8%)约236.84是把反向还原当直接扣减的干扰，271.6/12.8%是换分母错误。数值接近不自动成为好选项，必须说明错误路径。实际命题不能把这一组数字照搬。
- 图形：若规则说“交点递增”，线段端点恰好接触会让交点定义含糊，应重绘成明确穿越或明确分离。程序计数正确不能替代实际图像检查。
- 难度：短设问的病句题可能四项都很长；资料题虽短却需要多次跨行取数。记录实际阅读与计算负担，再说明难度，不只看题干长度。

## review.json

独立完成后记录如下字段。哈希由 `quality_gate.digest()` 按排序键的规范JSON计算，不是原文件字节哈希。完整题库哈希覆盖题目及材料；蓝图哈希单独记录，防止改材料/重排选项后复用旧结论。

```json
{
  "bank_sha256": "规范JSON({questions,materials})的SHA256",
  "blueprint_sha256": "规范JSON(blueprint)的SHA256",
  "method": "先隐藏答案独立求解，再比较；说明实际使用的流程",
  "unresolved": [],
  "deviations": {},
  "artifacts": {
    "numeric": {"path":"checks/numeric.py","sha256":"文件字节SHA256","executed_at":"实际执行时间"}
  },
  "records": [{
    "number":1,
    "question_sha256":"规范JSON(本题)的SHA256",
    "blind_answer":"B",
    "reasoning":"独立推导；不是粘贴作者解析",
    "wrong_option_reasons":{"A":"具体错误","C":"具体错误","D":"具体错误"},
    "unique_best_answer":true,
    "source_fit":"题位与模板依据、实际负担为何相符",
    "originality":"查过哪些范围，以及结构和材料比较结论",
    "difficulty_reason":"实际阅读、知识、步骤和干扰如何形成该档",
    "fact_check":{"mode":"verified","verified_at":"核验日期","reason":"具体官方条文及对应判断"}
  }]
}
```

数量/资料和实际需计算题记录 `calculation_artifact`（例如 `numeric`）；底稿须实际存在、哈希匹配并执行，另保存结果日志。图形记录 `graphic_visual_review` 的具体结果。知识题无现实事实、纯概念推导时可以 `fact_check.mode=conceptual`，须解释原因，不能借此绕过政策核验。

原始评分与题位目标不同时记录 `difficulty_calibration_reason`。单题长度或步数偏离分别写 `length_deviation_reason`、`calculation_deviation_reason`；整卷长度偏离在 `deviations.total_reading` 记录实际值、目标差值及原因。偏差说明是供审阅的证据，不是无条件豁免；仍然明显不像基准的题必须重写。

`quality_gate.py` 会检查覆盖、哈希、三个错项理由、基准匹配、步骤标注、复算底稿及材料规格。但它不能判断理由是否真实充分、来源是否权威或事实是否正确；运行结果明确保留这一限制。最终仍须逐题审阅和实际浏览器验收。

## 模型或设备能力不足时

缺少原 PDF 不构成内置模式的阻塞；缺少浏览器可先完成题库、构建和代码测试，最终明确尚未验证浏览器，不能声称交互已验收。若图像不可读或政策事实无法核实，改用能力范围内但仍满足题位的原创题；不能把图形题换成常识凑数。遇到无法消除的双解或错误，保留为未解决，不强行发布合格卷。
