# 考点轮换、图形质量与排序泄题检查

本规范用于每次命题前选题及交付前复核。以下去重与质量限制是用户反馈形成的生成要求，不是八套真题统计结论；不能回写或虚构源样本频次。

## 先选本卷方案，再冻结题位

固定的是选定 profile 的模块、二级题型配额、材料规格及难度目标；`blueprint.json` 中的细考点和题材是可轮换示例，不是每套必须重复的菜单。19类模板是有证据的参考，不是19道题的换数生成器。

1. 从本次依据中列出可用考点和变体，并记录依据。内置模式使用 baseline、templates 和 source-metrics；外部依据模式使用报告页码或真题题号。没有依据的变体不能仅为随机性加入。
2. 读取可用旧卷及 `generation-history.json`，优先比较最近三套和用户指明的问题卷；更早记录可用时也筛查同骨架。记录实际比较文件与缺失范围。
3. 在固定二级配额内，根据源样本频率加权选择细考点，对近期用过的具体推理骨架降低权重。保存实际 seed、候选集、选择结果及依据到 `work/selection-plan.json`；seed 只复现抽样，不能证明原创。候选量不足时保留高频知识点，改变实质推理结构，不能引入不符依据的冷僻题凑差异。
4. 写出每题的主要考点、求解骨架、设问目标、干扰机制、表示形式、难度依据，再冻结本次 `work/blueprint.json` 及哈希。不得先沿用上卷出完题，再补写“随机方案”。专项卷在用户指定模块内执行同样流程，配额按其适配蓝图，不硬凑100题。

## 图形：识别规律而非照提示执行

- 五题按主导解法区分。默认最多一题纯直接计数，禁止两题都只是数点/数区域再做简单递增或相加。数量规律可以考：须审查计数对象的识别、组织方式、与其他属性的联系和选项干扰，不能把“数量题”整体禁掉。
- 不再固定“数量2、位置1、复合2”。在依据支持的数量、位置、属性、样式/运算、空间等家族中选择；不要求每卷凑齐所有家族。复合题按真正参与求解的关系区分，不能给同一个旋转题换填充就当成另一种思维任务。
- 题干使用中性设问；通常不写“观察数量关系”“忽略外轮廓”“同时观察方向与填充”“前两幅合成第三幅”等直接点明本题规律的提示。必要的规则说明仅定义符号、读图或操作约定，不能代替发现规律。
- 中档题必须有实质辨识：例如选择有效属性、比较竞争规律、识别行列联系或追踪相互制约的变化。两条机械独立循环、图形较多、线条复杂或SVG精美，均不能自动证明中档。
- 为每个错误图形写出具体误读：只满足一部分关系、操作顺序颠倒、忽略方向等；至少两个错项能由合理误判产生。逐格验证完整规则和每个候选，检查旋转/对称导致的等价及其他同样简洁的解释。不能为增难画得模糊、堆规则或制造争议规律。
- 独立复核保留无提示图形视图、规则验证表、各选项排除依据和实际渲染检查。原评分“图形搜索+2”仅是历史描述口径，不能单凭它让简单计数题通过中档验收；不符目标就重写。

## 事件排序：不在题干提前叙述答案

- 中性背景加打乱的事件条目，依事件间因果、状态变化或必要依赖确定最佳顺序。禁止先用“先……随后……再……最后……”叙述完整流程，再把该流程编号让考生对照。
- 不能仅把连接词删掉却保留按正确顺序排列的同义复述；也不能用连续日期、已排序编号或条目措辞直接编码整条答案链。时间信息可作为合理证据，但不能退化为纯按日期大小抄顺序。
- 少量明确先后条件可以保留。逐题列出：题干直接给出的依赖、需要读懂事件才推出的依赖、区分最强干扰项的关键判断。若整条链已给出，或剩余只有常识性首尾接续，不能算合格中档排序题。
- 脱离选项先重建顺序，再逐项验证；存在多个合理顺序时补足有意义的条件或重写。不能为了防泄题删掉决定唯一性的条件，也不能强行把可并行的流程说成唯一顺序。
- 错项应在关键依赖处犯错，而非全靠“验收在施工前”等明显颠倒。五题应变化依赖结构与推断方式，不能全为同一种线性行政/生产流程换场景。
- 自动搜连接词只能提示风险，不能替代语义审查；“有先后词”不一定不合格，“没有先后词”也不等于通过。

## 跨卷原创性记录

每题保存以下结构化记录到 `work/generation-history.json`。使用相对路径；迁移设备时可携带历史记录，不依赖本机路径或聊天。历史库是用户工作数据，不自动提交开源仓库。

```json
{
  "schema_version": 1,
  "papers": [{
    "paper_id": "本卷唯一ID",
    "profile_id": "实际profile",
    "seed": "实际抽样种子",
    "questions": [{
      "number": 1,
      "primary_concept": "具体主考点",
      "solution_skeleton": "消去人物、地名和具体数值后的条件关系及求解操作",
      "target": "所求对象和方向",
      "distractor_mechanisms": ["实际错因"],
      "representation": "文字、图形布局或数据组织形式",
      "theme": "材料主题",
      "closest_prior": "旧卷ID及题号；无历史时为null",
      "substantive_difference": "条件组织或必要推断如何不同"
    }]
  }]
}
```

用骨架和设问目标匹配潜在重复，再人工核对；标签相异不代表解法不同。去掉数字/姓名后，条件图、求解顺序、所求量和错项机制可一一对应的，按换皮题重写。高频知识点可复现，但须改变关键关系、逆向/正向设问、多条件整合等实质任务，不能只增加无关叙述。图形更换点/线/区域，排序更换施工/工艺/调研名称，也须接受同一检验。

输出重复审查的最近似题对、判断依据和重写记录，分别统计“同知识点”“同解法骨架”“仅换表面内容”；不要混成一个相似度。没有旧卷或历史时完成卷内检查，并明确未验证跨卷重复；不同设备只带skill不带历史时，不能保证避开它看不到的旧题。

## 交付前质量关口

在 `work/diversity-review.json` 保存 comparison_scope、selection_plan、graphic_records、sequence_records、nearest_pairs 和 unresolved。每条按题号记录判断、证据、修改及复验；图形记录主导机制与难度依据，排序记录显式/推导依赖与最强错项。未解决的泄题、浅层重复、歧义或难度失配应先重写再交付。

现有结构脚本不自动理解这些语义记录；脚本通过不能代替本项审查，不能把非空字段当作质量证明。
