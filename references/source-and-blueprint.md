# 来源与蓝图

## 报告路径

1. 搜索工作目录和用户指明目录，确认实际报告内容、页数和可读性。先提取全文；图表、统计矩阵、排版丢失处查看原页。阅读覆盖全报告，重点核对蓝图、其他 AI 命题规范、数据限制和质量控制章节。
2. 提取模块和二级题型配额、难度配额、地方/时政数量、材料组及每组题数、长度口径、数据精度、计算步骤、干扰项原则。每个关键规则保存页码或章节依据。
3. 报告中的建议与样本实测分开标记。报告若称某部分待核验，不把它升级为确认事实。检查各项配额相加一致、题型体系与正文一致。
4. 只有报告时，可以按照报告进行命题；不能宣称已经阅读或完成与八套原卷的逐题查重。检查报告引用的题例及当前可用旧题，并明确查重范围。

## 八套真题路径

1. 建清单：文件名、哈希、卷内年份/批次、页数、题号范围、答案范围、扫描/OCR风险、缺页。真实不足八套就报告实际数量，不虚构缺卷。
2. 全页读取并逐题关联来源页、原题号、材料组及答案。OCR文字不能直接等同原图；图形、表格、单位、负号、幂次、选项字母及答案错位须复核。未知答案留空，原书答案与独立判断分开。
3. 全部可识别题目按实际出现的分类体系标注：主/辅助知识点、设问、材料及长度、选项长度和干扰机制、计算与推理步骤、地方特色、答案、分析性难度和识别可信度。部分确认与待核验不进入相应指标的确认分母。
4. 比较各套结构、题型覆盖、长度分布、计算量、难度、地方题和答案分布。知识点频次同时报告题数和覆盖套数；识别底层解法相同而题面不同的模式。材料本体只计一次，不对组内每题重复累加阅读量。
5. 模拟结构默认选出现次数最多的完整结构，并列取最近年份采用者；需要适配总题量时以相关结构的题型占比使用最大余数法分配。记录这个选择是本次命题规则，不是官方规定。难度由固定的阅读、知识、信息提取、计算/推理步骤及干扰强度规则估计，不冒充考生实测。

## 冻结文件

`work/blueprint.json` 是可执行配额，`work/source_manifest.json` 保存来源和限制；可以另设逐题位 `slots`，至少包括题号、模块、题型、主考点、难度、材料组和长度/计算目标。为关键模式附报告页码或“年份—题号—页码”证据索引。

对材料长度、精算/估算比例、地方题等补充指标做实际对比，而不仅检查总题量。确需偏离则记录数量和原因，不能为使统计达标而修改实际标注。

内置模式已有来源摘要与可执行蓝图，无需重新定位原报告。只有用户要求更新或替换基准时才执行上述外部路径。新基准与内置基准分别保存，不能覆盖版本后仍沿用旧 profile ID。
