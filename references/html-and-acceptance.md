# HTML 实现与验收

## 数据及页面

同一题库生成考题、答题卡和解析，以题号关联。文本转义后渲染；内嵌 JSON 时转义 `<`，避免 `</script>` 破坏页面。图形优先自包含 SVG，使用 viewBox；不要让图片必须联网才能显示。资料表保留单位、表头和精度，窄屏横向滚动；提供图形放大及关闭按钮，放大后仍能看全标签。

首页明确题量、时间、分值和规则。点击开始才展示整卷并计时。默认整卷滚动，桌面侧边答题卡，手机顶部可展开答题卡，跳题时避免粘性页头遮挡。选项有清晰点击区域和键盘交互，长文字自然换行。提交前不向可见 DOM 或辅助技术显示答案、解析、考点及事实来源；离线 HTML 源码包含答案，不能承诺防作弊。

## 状态机

`ready → running → submitted`。版本键由卷 ID 和内容版本组成。存储至少包含版本、开始时间、绝对截止时间、选择、提交状态、提交原因和最终结果。验证恢复的数据类型、题号和选项范围；破损存储给明确信息，不能把坏值算分。

- 运行时剩余时间为 `max(0, deadline - Date.now())`，不能靠每秒递减变量作为唯一时钟。
- 开始后不暂停；刷新或重新打开先判断截止时间，到期立即按已保存答案结算。
- 选择事件、页面恢复和交卷前都检查到期，避免后台定时器节流后接受过期答案。定时器更新只负责显示和触发检查。
- 提前交卷确认框显示未答数；取消保留全部状态。确认框打开期间到时也要自动提交。
- 结算幂等，提交后禁止改选，不重复累计分数；全对100、全错/全未答0。若不是100题，按用户分值规则计算，说明舍入方式。
- localStorage受限时明确提示无法持久保存，但当前页内仍正常考试。关闭期间进度恢复只在存储可用时承诺。计时基于本地系统时钟，不宣称能防止人为修改设备时间。
- 重考需确认，清除当前版本的本次记录，不清空整个 localStorage。使用 storage 事件时防止旧运行状态覆盖已提交状态。

## 提交结果

显示总分、正确/错误/未答数量及各模块得分。每题下显示：

> 你选的是：B　错误❌（或“你未作答”）  
> 正确答案：C  
> 解析：完整过程。  
> 一级模块 · 二级题型 · 核心考点

正确/错误也以文字表达，不仅用颜色。题下解析默认尽量覆盖 A/B/C/D 的成立或排除依据，具体按题目质量规范执行；检查最终页面显示了这些理由，而非只存在于复核底稿。

提交后图形放大、材料回看继续可用。

## 必测行为

对最终文件用真实浏览器打开 `file://` 并禁用网络验证。使用隔离浏览器上下文；测试自动填满不影响用户真实作答进度。

覆盖全对、全错、部分作答、全未答、确认/取消提前交卷、运行中刷新、超时后重新打开、确认框中超时、重复提交、结果刷新、重考确认/取消和存储不可用。检查题量、选项、提交前隐藏、提交后全部解析及锁定；通过时间控制或注入测试截止时间避免真等90分钟。

检查320/375像素手机、768像素平板和桌面宽度，遍历题卡与选项边界；复杂表格内部滚动可以接受，整个页面不能横向溢出。实际看包含长题、长解析、图形、表格、首页和结果的截图，不能仅截图不看。检查键盘操作、放大关闭、跳题和页头遮挡。

单文件不得包含外部脚本、字体或必须远程加载的图片；解析的可选来源链接不算运行依赖。测试无脚本异常和离线必需资源缺失。记录浏览器、断网条件、测试数、最终路径与 HTML 哈希，不把旧文件的测试结果用作修改后文件的证明。
